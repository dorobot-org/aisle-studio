# SO-101 follower model

The URDF and its 13 STL files come from the LeRobot robot-urdfs dataset at revision
[1b184a0e9ea822b8f8bfd1382f3ae0b28e1bfad3](https://huggingface.co/datasets/lerobot/robot-urdfs/tree/1b184a0e9ea822b8f8bfd1382f3ae0b28e1bfad3/so101).
The assets originate with [TheRobotStudio's SO-ARM100 project](https://github.com/TheRobotStudio/SO-ARM100/tree/main/Simulation/SO101)
and are distributed under the accompanying Apache 2.0 license. Keep the STL files
under `assets/` so the relative URDF references resolve.

Trailing whitespace on one URDF line was removed locally.
